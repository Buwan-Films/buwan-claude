Buwan Films · Premiere Pro

Editing a wedding in Premiere with Claude

Claude does the prep: importing, bins, colors, culling, syncing, audio cleanup and the first cut. You handle the creative work. Copy the prompts on this page and paste them into Claude.

Once per laptop

Set up your laptop

  • All your jobs go in here. In Terminal:

    mkdir -p ~/Buwan
  • cd ~/Buwan && claude --dangerously-skip-permissions

  • Paste each line into Claude. When it asks for your editing app, choose premiere, and enter your name.

    /plugin marketplace add Buwan-Films/buwan-claude
    /plugin install buwan@buwan-films
    /plugin install buwan-premiere@buwan-films

    Quit Claude afterwards (type /exit) and open it again with the command from the step above.

  • /buwan:setup-kit

    It takes 3–6 minutes.

  • This is how Claude controls Premiere. Close Premiere, then run this in Terminal (not in Claude):

    npx -y premiere-pro-mcp@1.11.5 --install-cep

    Open Premiere again. You should now see Window → Extensions → MCP Bridge.

  • Run this in Terminal:

    claude mcp add --transport http --scope user artlist https://mcp.artlist.io/mcp

    Then in Claude, type /mcp, choose artlist, and sign in with the studio's Artlist account.

  • Herdr gives each wedding its own session, so you can come back to it later. Run this in Terminal:

    brew install herdr

    If Terminal says brew: command not found, install Homebrew from brew.sh first. Type herdr to open it. Its guide is at herdr.dev.

  • /buwan:check

    Claude lists anything that's missing and tells you how to fix it.

Step 11 min
You

Open this wedding's own session

Every wedding gets its own session, named after the couple, so you can come back to it days later. Open Terminal and run these two lines, changing Ana-Ben to the couple's names:

herdr --session Ana-Ben
cd ~/Buwan && claude -n Ana-Ben --dangerously-skip-permissions

The first line opens a Herdr session for this wedding. The second starts Claude inside it, with the couple's names as the session name.

This lets Claude work without asking you to approve each step. Your original footage stays protected either way.

Step 25 min
You

Make the job folder and the Premiere project

In Finder, create this inside Buwan/projects/. Name it with the wedding date and the couple's names, and give each shooter their own folder.

2026-11-14_Ana-Ben_wedding/
├─ footage/
│  ├─ 1-Main/
│  ├─ 2-Creative/
│  ├─ 3-Reactions/
│  ├─ 4-Drone/
│  └─ Audio/          ← audio recorder / lav files
├─ music/
└─ edit/

Then in Premiere:

  1. File → New → Project. Save it in the edit folder as Ana-Ben_v1.prproj.
  2. Create one sequence at 23.976 fps, 1920×1080, 48 kHz. Leave it empty.
  3. Open Window → Extensions → MCP Bridge. It should say Running.

Then ask Claude:

verify Premiere connection

If everything comes back ready, Claude can control Premiere.

Step 35 min
You

Add the clips and the music

Clips: copy each shooter's card into their folder. Don't import anything into Premiere. Claude does that.

Music: pick two tracks from Artlist and save them in the music folder:

  • 01_intro: the opening hook, with no talking over it
  • 02_story: the main track, which runs to the end. Claude puts the kiss on its biggest moment, so choose one that builds.

With Artlist connected, you can ask Claude for a track, for example:

Use Artlist to find an emotional, building wedding track for 02_story and save it in the job's music folder

If Claude only gives you a link, open it on artlist.io, download the track, and save it in music yourself. You can also drag tracks in from Artlist's panel in Premiere, and Claude will find them there.

Step 415–25 min
Claude

Start the prep

Paste this, with your job's name and the look you want:

/buwan-premiere:wedding-day 2026-11-14_Ana-Ben --footage "projects/2026-11-14_Ana-Ben_wedding/footage" --music "projects/2026-11-14_Ana-Ben_wedding/music" --grade warm

Use warm for daytime or garden weddings and cool for hotel, ballroom or cloudy days.

Claude asks what time the video screens, then works on its own and updates you as it goes. When it's done, your Premiere project has:

  • Every clip imported and sorted into the studio bins, with the studio color labels
  • Bad clips (black, out of focus, false starts) moved into 00 Rejected, with a reason for each
  • All cameras synced by sound, with one SYNC sequence per moment. Turn on Multi-Camera on each one.
  • Speech clips with the silences cut out, and an A-Roll clean sequence so you can hear the whole day quickly
  • The studio LUT on every camera clip, and dialogue leveled and cleaned up
Step 520–40 min
You + Claude

Pick the story

/buwan:plot

Claude transcribes the vows, letters and speeches and puts together a story in order. Read it, tell Claude what to change, then approve it. Check the spelling of any names or places Claude flags.

Step 610 min
Claude

Claude builds the first cut

Once you approve the story, Claude makes a new sequence called SDE Cut. It's cut to the music, with the kiss on the music's peak, already graded and leveled. Your other sequences aren't touched. Claude also checks the pacing against the studio rules.

Step 7until screening
You

Finish and export

Watch the SDE Cut. Swap any shots you don't like, adjust timing and add speed ramps. Then run each of these in order:

PromptWhat it does
/buwan:graphicsAdds the title and logo from the Buwan kit
/buwan:sfxAdds whooshes, risers and hits
/buwan:reviewA final watch-through with Claude
/buwan:exportExports the master to the exports folder
/buwan:clipperMakes vertical reels for Instagram and TikTok
Good to know

More clips arrive during the day

Put them in the same shooter folders and paste:

/buwan-premiere:wedding-day 2026-11-14_Ana-Ben --new-clips

Claude only adds the new clips. If they change the story, it makes an SDE Cut v2 and leaves v1 alone.

Corporate events

Start with this instead of Step 4:

/buwan:intake 2026-11-20_Acme corporate "/path/to/footage"

Then run /buwan:assemble, then /buwan-premiere:premiere-apply, and continue from Step 5.

Coming back to a wedding later (enhancements, revisions)

Days or weeks after the wedding, reopen that wedding's session. Claude remembers everything from before: the story you picked, the cut, the notes.

If the laptop hasn't restarted, reattach the Herdr session:

herdr session attach Ana-Ben

If the laptop has restarted, or the session above is gone, reopen Claude by name:

herdr --session Ana-Ben
cd ~/Buwan && claude --resume Ana-Ben --dangerously-skip-permissions

Forgot the name? Run cd ~/Buwan && claude --resume with no name to pick from a list of past sessions.

Before you work in the session, open that wedding's project in Premiere (edit/Ana-Ben_v1.prproj). Only work on one wedding at a time in Premiere, because it only has one project open.

If Claude can't reach Premiere

  1. Check that a project and a sequence are open in Premiere.
  2. Check that Window → Extensions → MCP Bridge says Running.
  3. Close any pop-up windows in Premiere, then try again.

Claude never changes your original footage, never deletes anything from your project, and always builds its cuts as new sequences.

Checkboxes are saved in your browser only.
