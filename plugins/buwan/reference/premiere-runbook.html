Buwan Films · Premiere Pro

Editing in Premiere with Claude

Laptop setup and every job, for weddings, prenups, corporate events and commercials. Claude makes the enhanced clips, imports them, transcribes the speech and, when you ask, syncs the vows, plots the story and builds the cut. You make the calls. Copy the prompts and paste them into Claude. The whole studio flow, by role: Buwan Films Workflow.

Once per laptop

Set up your laptop

  • All your jobs go in here. In Terminal:

    mkdir -p ~/Buwan
  • cd ~/Buwan && claude --dangerously-skip-permissions

  • Paste each line into Claude. When it asks for your editing app, choose premiere, and enter your name.

    /plugin marketplace add Buwan-Films/buwan-claude
    /plugin install buwan@buwan-films
    /plugin install buwan-premiere@buwan-films

    Quit Claude afterwards (type /exit) and open it again with the command from the step above.

  • /buwan:setup-kit

    It takes 3–6 minutes. It also installs the local transcription (whisper) and the stabilizer.

  • This is how Claude controls Premiere. Close Premiere, then run this in Terminal (not in Claude):

    npx -y premiere-pro-mcp@1.11.5 --install-cep

    Open Premiere again. You should now see Window → Extensions → MCP Bridge.

  • Run this in Terminal:

    claude mcp add --transport http --scope user artlist https://mcp.artlist.io/mcp

    Then in Claude, type /mcp, choose artlist, and sign in with the studio's Artlist account.

  • Herdr gives each wedding its own session, so you can come back to it later. Run this in Terminal:

    brew install herdr

    If Terminal says brew: command not found, install Homebrew from brew.sh first. Type herdr to open it. Its guide is at herdr.dev.

  • /buwan:check

    Claude lists anything that's missing and tells you how to fix it.

    Updates: when the owner says the rules changed, run /plugin marketplace update buwan-films, then /reload-plugins.

Every job

A job, start to finish

You do this Claude does this
Beforeweeks ahead
Owner + you

Plan on the Storyboard page

The job is planned on the Buwan Storyboard: brief, music, beats, cards, the shot list the crew ticks on the day, and the BTS social plan. After the client signs off, export the bundle (.zip). You unzip it into the job in step 2.

Step 11 min
You

Open this job's own session

Every job gets its own session, named after the client, so you can come back to it days later. Open Terminal and run these two lines, changing Ana-Ben to the couple's or client's name:

herdr --session Ana-Ben
cd ~/Buwan && claude -n Ana-Ben --dangerously-skip-permissions

The first line opens a Herdr session for this job. The second starts Claude inside it, with the name as the session name.

The last option lets Claude work without asking you to approve each step. Your raw footage stays protected either way: the plugin blocks any write into the raw, card and sources folders.

Step 25 min
You

Make the job folder and the Premiere project

In Finder, create this inside Buwan/projects/. Name it with the date, the client and the shoot type (wedding, prenup, corporate or commercial): the shoot type tells the engine how to treat the footage.

2026-11-14_Ana-Ben_wedding/
├─ footage/
│  ├─ 1-Creative/Glider/
│  ├─ 2-Main/
│  ├─ 3-3rd Cam/
│  ├─ 4-Drone/
│  ├─ Audio/          ← audio recorder / lav files
│  └─ 5-BTS/          ← behind the scenes for social, kept as shot
├─ music/
└─ edit/
   └─ storyboard/     ← unzip the Storyboard bundle here

Then in Premiere:

  1. File → New → Project. Save it in the edit folder as Ana-Ben_v1.prproj.
  2. Create one sequence at 23.976 fps, 1920×1080, 48 kHz. Leave it empty.
  3. Open Window → Extensions → MCP Bridge. It should say Running.

Then ask Claude:

verify Premiere connection

If everything comes back ready, Claude can control Premiere.

Step 35 min
You + data wrangler

Add the clips and the music

Clips: copy each card into its camera folder, then make a second copy on another drive. Never format a card until the job is closed. Don't import anything into Premiere: Claude does that.

Music: the tracks from the storyboard, licensed on Artlist, saved in the music folder. Weddings use two (01_intro with no talking over it, 02_story that builds to the end); prenups and commercials use one. Place them in your sequence yourself.

With Artlist connected, you can ask Claude for a track, for example:

Use Artlist to find an emotional, building wedding track for 02_story and save it in the job's music folder

If Claude only gives you a link, open it on artlist.io, download the track, and save it in music yourself. Keep the licence ID: /buwan:deliver asks for it.

Step 4about 40 min for 5 h
Claude

The basics: enhanced clips

Paste this, with your job's name:

/buwan-premiere:wedding-day 2026-11-14_Ana-Ben_wedding --footage "projects/2026-11-14_Ana-Ben_wedding/footage"

Same command for every shoot type; the folder name sets the type.

Claude asks what time the video screens, then writes a new folder next to your footage, footage_ENHANCED_<date-time>, with every clip of the day. Your footage folder is only read.

  • Exposure and white balance fixed on every clip that needs it (weddings keep their natural warmth; corporate and commercial jobs stay brand-true)
  • Shaky Creative / Glider shots cut to their best part and smoothed
  • Every other clip copied as it is, including 5-BTS
  • No grade: the look comes later, in Premiere

Then it stops. Bring the folder into Premiere:

Import the enhanced folder into Premiere

One bin per camera. Drone clips are Teal, clips with speech are Mango with their first words in Description (search a word from the vows to find the clip), BTS clips are Rose. No sequences are made for you.

Step 5during the day
Claude

New cards, transcripts and missing shots

Each time new cards land in the camera folders:

/buwan:sync 2026-11-14_Ana-Ben_wedding

Only the new clips are fixed and added to the same enhanced folder. Then every clip with speech is transcribed on this laptop (vows, mass, speeches; keynotes and panels for corporate; testimonials for commercials). Ask for the import again: only the new clips come in.

Ask Claude which must-have shots from the storyboard are still missing, and tell the lead shooter while they can still get them.

Step 6on request
You + Claude

Vows, speeches and interviews

Name the clips of one moment, every angle plus the lav or recorder file:

/buwan:multicam 2026-11-14_Ana-Ben_wedding --moment "Bride vows" --type vows --clips C0823 C0017 ZOOM0003

The angles are synced on the best audio, the dead air is cut on every angle, and the audio is cleaned. Types: interview, vows, speech, keynote, panel, testimonial, voiceover.

Step 720–40 min
You + Claude

Story-Lock

/buwan:plot

Claude puts the real transcript lines into the storyboard's beats, word for word, Taglish kept. Prenups get a Shot-Lock (the best take per planned shot); commercials follow the approved script. Read it, tell Claude what to change, then approve it. Check the spelling of any names Claude flags.

Step 810–30 min
Claude, then you

Rough cut and the proof gate

/buwan:rough-cut

B-roll from the ticked shots, holds and bursts where the storyboard says, cut to the music. The proof gate then measures the pacing for the shoot type. Fix what fails, or write why you are overriding it.

Same-day edit with a screening tonight: /buwan:sde runs Story-Lock to export compressed. The gates still apply.

Step 9until screening
You

Finish, export and deliver

Watch the cut. Swap any shots you don't like, adjust timing and add speed ramps. Then run these in order:

PromptWhat it does
/buwan:audioDialogue −17 LUFS, peaks −6, music bed −20 dB
/buwan:gradeThe look. Pick the Buwan LUT once by hand in Lumetri (Creative → Look); Claude copies it to every camera clip and checks it
/buwan:graphicsCards and captions from the Buwan kit, with the storyboard's text
/buwan:title · /buwan:end-cardThe couple's names, then the logo end card as the last shot
/buwan:sfxWhooshes, risers and hits under the dialogue
/buwan:reviewA watch-down with the owner, against the storyboard
/buwan:exportThe masters into exports
/buwan:clipperVertical reels
/buwan:deliverDelivery note, music licence record, backup check, then archive

BTS posts are the BTS person's job with /buwan:bts, never before the earliest post date.

Good to know

More clips arrive during the day

Put them in the same camera folders and paste:

/buwan:sync 2026-11-14_Ana-Ben_wedding

Only the new clips are fixed, added and transcribed. Then ask for the import again.

Prenup, corporate and commercial jobs

The same steps. Name the folder with the shoot type, e.g. 2026-11-20_Acme_corporate or 2026-12-02_Brand_commercial.

If the folder name doesn't say it, add --shoot corporate (or prenup, commercial) the first time.

Coming back to a job later (enhancements, revisions)

Days or weeks later, reopen that job's session. Claude remembers everything from before: the story you picked, the cut, the notes. Client revision notes go through /buwan:review.

If the laptop hasn't restarted, reattach the Herdr session:

herdr session attach Ana-Ben

If the laptop has restarted, or the session above is gone, reopen Claude by name:

herdr --session Ana-Ben
cd ~/Buwan && claude --resume Ana-Ben --dangerously-skip-permissions

Forgot the name? Run cd ~/Buwan && claude --resume with no name to pick from a list of past sessions.

Before you work in the session, open that job's project in Premiere (edit/Ana-Ben_v1.prproj). Only work on one job at a time in Premiere, because it only has one project open.

If Claude can't reach Premiere

  1. Check that a project and a sequence are open in Premiere.
  2. Check that Window → Extensions → MCP Bridge says Running.
  3. Close any pop-up windows in Premiere, then try again.

Claude never changes your original footage, never deletes anything from your project, and builds any cut as a new sequence.

Checkboxes are saved in your browser only.
