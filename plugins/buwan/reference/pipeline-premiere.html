Before · you, by hand

Make the project

  1. Hand the raw clips over on the SSD, one subfolder per shooter: 1-Main, 2-Creative (or Glider), 3-Reactions, 4-Drone, Audio.
  2. New Premiere project saved in <raw>_WORK/PROJECT/; File → Project Settings → Scratch Disks all on that folder.
  3. Drop your music in where you want it. Claude Code doesn't touch it.
  4. Window → Extensions → MCP Bridge running; start Claude Code in your Buwan workspace.
The basics · Claude Code · one run, unattended

Six things, then stop

  1. Dedupe + working copy — the raw clips mirrored into <raw>_WORK/RAW_COPY/ on the same SSD, every file verified by SHA-256, byte-identical duplicates skipped and logged (logs/dedupe_report.md). Only the copy is read from here on.
  2. Cull — false starts, black, blown and dead clips rejected. Flags, never deletions.
  3. Categorize — every clip into one of the 12 studio categories (Speech, Prep & Details, Portraits, Ceremony, Reactions & BTS, Establishing, Reception & Party, Drone, Music, SFX, Graphics, Grade & Adjust).
  4. Dead air — the speech inside every speech clip found, silences cut; cleaned −17 LUFS WAVs in AUDIO_CLEAN/; the A-Roll clean is the whole day's speech back to back.
  5. Label colors — Premiere label per category (Speech Mango · Prep Tan · Portraits Yellow · Ceremony Violet · Reactions Rose · Establishing Cerulean · Reception Magenta · Drone Teal · Music Forest). Every clip into its bin. Soft-focus, dark, blown and frozen b-roll parked in 00 Flagged/<reason>, label kept.
  6. Shaky — Creative/Glider only — the longest steady stretch (≥2.5 s) becomes a Steady pick (the best cut is always chosen first); no steady stretch on a gimbal shot → its best cut placed in the STABILIZE – Warp sequence with Warp Stabilizer applied; handheld or nothing to save → Flagged, not stabilized. Shaky clips on other cameras are left alone.
Stops here · no sync · no story · no cut · no music
Only when you ask

Separate skills

  • Multicam — /buwan:multicam: vows, interviews, ceremony synced by audio; wrong camera clocks don't matter.
  • Story — /buwan:plot: transcribe the A-Roll clean (Taglish verbatim), tag beats, pick lines.
  • Cut — the music-driven timeline, proof gate, grade, levels: /buwan:sde.
  • Finish — /buwan:graphics · /buwan:sfx · /buwan:export.
