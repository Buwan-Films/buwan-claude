# 07 Review — taste only

## 1. Confirm the gates
Before the watch-down, confirm and list: proof gate PASS (or override), audio specs PASS, grade check PASS, graphics converge done. If any is missing, run it first — review is not the place to find measurable problems.

## 2. Watch-down sheet
Create `edit/review_vN.md` for the editor to fill while watching the full film once without stopping:
| TC | Beat | Feel (works / drags / rushed / flat) | Note |
Prompts per part (wedding): Does the intro pass the 5–10 second test? Does the storyline make us care about both people? Do the holds on vows and first looks breathe (15–20s, no cutaways)? Is the burst montage at the energy peak and on the beat? Does the outro resolve? Corporate: do holds sit on speakers and the keynote's key line?

## 3. Client revision notes
If the editor pastes client feedback: turn it into a numbered revision list `# · TC · request · type (story / timing / graphics / grade / audio) · effort · conflicts with house rules?` Flag requests that break house rules (e.g. "add more text", "make it brighter than the look") so the owner can decide. Draft a short, polite reply to the client confirming what will change.

## 4. Sign-off
Record who approved and when at the top of the review file. Only then go to `/buwan:export`.
