# Buwan studio pages

The claude.ai pages the team works from. The rules live in this repository; these pages are the visual versions for people. A copy of each page is kept in `plugins/buwan/reference/` (see [MAINTAINING.md](../MAINTAINING.md) for how to update them). Pages open only for people the owner has shared them with.

| [Wedding Film Playbook](https://claude.ai/artifact/Es7pa3RkpeStAh3omA5xMa) | Director's binder for a Filipino Catholic wedding: a shot list per segment (prep → reception, incl. arrhae, veil and cord, Consecration rules) with must / should / bonus, shot cards, crew positions and a sample run of show, camera and lens notes. Use it as the reference when building a wedding storyboard. **Older than the house rules in places:** it says Cam A / B / C (the studio's cameras are Creative / Glider, Main, 3rd Cam, Drone, Audio, BTS), allows Log "if you have time" (house rule: no S-Log on same-day jobs), and its 3–5 min three-act SDE is replaced by the SDE Reference shape (4–7 min, two peaks) | `reference/wedding-film-playbook.html` |
| [Buwan Premiere Runbook](https://claude.ai/artifact/EB1wxv3VXbFY1b8oitFuik) | First version of the Premiere editor guide: laptop setup (plugins, kit, MCP Bridge panel, Artlist connection, Herdr sessions per wedding) and coming back to a wedding later with `claude --resume`. **Superseded for the job steps** by the Premiere Pro Pipeline and the Workflow: its footage folders (1-Main, 2-Creative, 3-Reactions) are not the studio's (1-Creative/Glider, 2-Main, 3-3rd Cam, 4-Drone, Audio, 5-BTS), and its step 4 (`wedding-day --music --grade warm` building bins, LUT and the SDE Cut) is no longer what the basics do — the basics make the enhanced clips, no grade, and stop | `reference/premiere-runbook.html` |
| [Buwan SDE Reference](https://claude.ai/artifact/RDUxcBdi9RpZuzmnE9Ysh3) | The measured reference SDE: the shape every same-day edit follows and the proof gate's SDE targets | `reference/sde-reference.html` |
